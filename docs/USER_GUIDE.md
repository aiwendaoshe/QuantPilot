# QuantPilot 用户使用文档

> 版本 v0.4.0 · A 股短线选股桌面软件（Windows / macOS）  
> 本软件仅供研究学习与辅助决策，**不构成任何投资建议**；股市有风险，入市需谨慎。

---

## 1. 安装

### Windows

1. 双击 `QuantPilot-Setup-0.4.0.exe`（在 `release/` 目录或分发包内）。
2. 按引导安装（可自定义安装目录），完成后桌面与开始菜单会出现「QuantPilot」快捷方式。
3. 首次启动会自动初始化本地数据库（位于 `C:\Users\<你>\AppData\Roaming\QuantPilot\quantpilot.db`），**不会**写入安装目录。

### macOS

打开 `QuantPilot-0.4.0-mac.dmg`，把 QuantPilot 拖入「应用程序」即可。

### 可选：接入真实行情（强烈建议）

不装 Python 时软件用「内置模拟数据」运行（界面完整、可体验全部功能，但数据是合成的）。  
接入真实 A 股历史行情：

```bash
# 安装 Python 3（3.9+）后执行
pip install baostock
```

装好后重启 QuantPilot，首次启动会自动拉取全市场日 K（后复权）+ 股票中文名称，之后每次启动只做增量更新。

## 2. 界面总览

| 页面       | 用途                                                           |
| -------- | ------------------------------------------------------------ |
| **仪表盘**  | 今日选股 TOP20 卡片（排名 · 代码 · 中文名 · 评分 · 信号类型 · 7 因子雷达），点击卡片进入个股详情 |
| **策略配置** | 7 个内置策略的参数调整与启停，保存后立即生效                                      |
| **回测**   | 任选策略 + 时间区间 + 初始资金 + 风控参数，一键回测出净值曲线/回撤/成交明细                  |
| **个股详情** | K 线（MA5/10/20 + 成交量 + 历史信号标记）+ 信号列表                          |
| **定时任务** | 每日收盘后自动选股，桌面通知 + 飞书群推送                                       |

顶部导航栏可在五个页面间切换。

---

## 3. 每日选股（核心流程）

1. 启动软件 → 仪表盘自动加载最近一次选股结果。
2. 点「立即选股」按当前数据重新计算（选股在后台线程运行，界面不卡顿）。
3. 卡片按**综合评分降序**排列；标签含义：
   - 🔴 **趋势**（趋势选股 / 均线多头 / 均线放量）
   - 🟣 **反包**（断板反包 / N 字反包）
   - 🔵 **突破**（海龟突破）
   - 🟢 **跌停反包**
4. 每张卡片的雷达图是 7 因子分解：趋势 / 量能 / 资金 / 板块 / 形态 / 波动 / 强度（满分 100）。
5. 「选股说明」一行给出触发理由（如：多周期共振·MA多头 4 向上·量比 3.33·ADX100），供人工复核。

> 建议习惯：收盘后跑一次选股 → 人工过一遍 TOP 名单的基本面/题材 → 次日开盘前定好计划。信号是"候选池"，不是买入指令。

## 4. 策略配置

内置 7 个策略（均线多头 / 趋势选股 / 断板反包 / N字反包 / 海龟突破 / 均线放量突破 / 上升跌停反包）：

- 每个策略有独立参数（阈值 / 窗口期 / 量比倍数等），在「策略配置」页动态渲染，改完点保存。
- 不想用某个策略就把它**停用**，选股结果随即只剩启用策略的信号。
- 参数保存后持久化在本地，重启不丢；回测与选股共用同一份配置。

---

## 5. 回测

1. 进入「回测」页，选择策略、起止日期、初始资金。
2. 风控参数：止损比例、止盈比例（0 = 不启用）、最长持仓天数。
3. 点「开始回测」，得到：
   - **净值曲线 + 回撤水下图**
   - 指标卡：胜率 / 盈亏比 / 夏普 / 最大回撤 / 交易次数
   - **成交明细表**（每笔：代码 / 名称 / 买卖日期 / 收益 / 持仓天数 / 退出原因）
4. 回测规则（引擎保证）：**T+1**（信号次日开盘成交）、含手续费与滑点、个股数据结束强制平仓、**严格无未来函数**（信号只用当日及以前 K 线）。

---

## 6. 定时任务 + 飞书推送

1. 进入「定时任务」页，打开开关并设置时间（如 **17:30**，收盘数据一般 17 点后齐全）。
2. 填入飞书群机器人 **Webhook 地址**（飞书群 → 设置 → 群机器人 → 自定义机器人 → 复制 Webhook）。
3. 到点自动选股，推送内容：命中数量 + TOP10 名单（名称/代码/评分/信号类型），同时弹 Windows 桌面通知。
4. 注意：定时选股依赖本程序处于运行状态（最小化即可，无需前台）。

## 7. 常见问题

| 问题                     | 处理                                                                 |
| ---------------------- | ------------------------------------------------------------------ |
| 数据一直是"华芯科技"这类假名字/价格不动？ | 未检测到 Python+baostock，正用内置模拟数据。按第 1 节安装 `pip install baostock` 后重启。 |
| 想看真实的股票中文名？            | 已内置 baostock 名称回填（query_stock_basic）；旧库若名称=代码，重跑一次数据拉取即可自动补全，无需删库。 |
| 数据库在哪？                 | `AppData\Roaming\QuantPilot\quantpilot.db`（Windows）。备份/迁移拷这一个文件即可。 |
| 选股/回测很慢或卡住？            | 计算默认在独立线程；如需排查可设环境变量 `QUANTPILOT_NO_WORKER=1` 回到主进程模式。             |
| 回测报告文件在哪？              | 开发模式 `data/reports/`；打包版日志见 `AppData\Roaming\QuantPilot\logs\`。    |
| 想清空数据重拉？               | 关闭软件 → 删除 `quantpilot.db` → 重启（首次启动自动全量回填）。                        |

## 8. 风险提示（务必阅读）

1. 全部策略基于**历史量价数据**的规则化筛选，不包含基本面、消息面与实时盘中信息。
2. 合成数据下的回测指标（高胜率等）**不代表真实行情表现**；请以真实数据回测结果为准，并理解过拟合风险。
3. 涨停/跌停相关策略受涨跌停制度、流动性、一字板无法成交等现实约束，回测成交假设偏理想。
4. 本软件输出仅为**研究参考**，任何交易决策及其后果由投资者自行承担。
